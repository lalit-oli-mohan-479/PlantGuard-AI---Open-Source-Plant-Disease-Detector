🌿 Core Challenge Focus

Touch Grass:
Connect with Living Nature

Screens are helpful for initial patterns, but genuine plant health happens out in the dirt. Step into natural sunlight, inspect living foliage, and nurture real soil.

Outdoor Care Checklist:

Inspect leaf underside for spores, mites, or ladybugs
Perform the 2-inch finger soil moisture test
Check canopy airflow and space between plants
Sanitize pruners with 70% alcohol before trimming
Breathe fresh air and enjoy 10 minutes outdoors

Model Specifications & Architecture

🧠 MobileNetV2 Backbone

Trained on the open PlantVillage dataset. Only ~3.5 million parameters and 8.9 MB weight footprint. Executes locally on CPU without dedicated GPU.

📜 Multi-Tier Open Licenses

Commercial apps charge $30–$60/year and collect private telemetry. PlantGuard AI is completely free, open-source, and offline-capable.

Developer Setup

Run the Python App Locally

Clone the official repository and launch the local Gradio dashboard: 

git clone https://github.com/lalit-oli-mohan-479/PlantGuard-AI---Open-Source-Plant-Disease-Detector.git
cd PlantGuard-AI---Open-Source-Plant-Disease-Detector
pip install -r requirements.txt
python app.py

To execute the full test suite (22 unit & integration tests): 

pytest -v
